# v3.2.3 입력 4종 표준

## 1. 학교기본정보
필수: 교번, 학교명, 학교급, 급지  
선택: 학교코드, 전의안표시명, 정렬순서, 사용여부  
추가 시트: 전보금칙설정, 개인금칙, 학교별칭

## 2. 정원·현원
필수: 학교명, 교원구분, 2.28정원, 2.28현원, 3.1정원  
2.28현원은 실제현원이며 누락 시 다음 단계 진행을 막습니다.

## 3. 관내전보·전입명부
필수: 성명, 생년월일, 교원구분, 배치유형, 현임교, 1지망, 2지망  
배치유형: 복직 / 복귀 / 관내전보 / 타시군전입 / 타시도전입 / 비정기전입 / 신규임용  
관내전보 순위는 별도 순위열보다 **명부 위→아래 순서**를 기본으로 사용합니다.

## 4. 관외전출·퇴직명부
필수: 성명, 생년월일, 교원구분, 현임교, 전출유형  
전출유형: 타시군전출 / 타시도전출 / 정년퇴직 / 명예퇴직 / 면직 / 휴직 / 파견 / 승진·전직 / 국립전출 / 기타  
해당자가 없으면 프로그램의 **관외전출 없음** 버튼으로 명시합니다.

## 업무 흐름
발령 및 전보설정 → 입력 4종 검증 → 결원 확정 → 자동·충원 배치 → 최종검증 → 전의안 → 발령통지서

프로그램은 예전 호환서식도 최대한 읽되, 표준서식이 아닌 경우 경고를 표시합니다.
