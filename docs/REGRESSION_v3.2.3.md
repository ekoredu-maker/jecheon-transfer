# v3.2.3 회귀검증 결과

- 학교기본정보 12교
- 정원·현원 12행
- 관내전보·전입명부 100명
- 관외전출·퇴직명부 12명
- 명부 위→아래 순위: 1~100 정상
- 결원확정: 관외확정 12명 / 내신 제외 12명
- 자동배치: 배치 78명 / 잔류 10명 / 관외확정 12명
- 만기 미배치 0명
- 지역만기 동일급지 배치 0명
- 최종 오류 0건
- 최종 미충원: 테스트홍광초등학교 초등교사 2명
- 최종 과원 0명

## 자동배치 정책 사례
- 상위순위 2지망 vs 하위순위 1지망 → 상위순위 우선 PASS
- 복직자 현임교 자리 없음 + 1지망 자리 있음 → 1지망 배치 PASS
- 지역만기 동일급지 1지망 차단 후 타급지 2지망 → PASS
- 가족교원 상피학교 자동배치 보류 → PASS
- 과원(-1) 학교 자동배치 차단 → PASS

## 오류유도 자료
다음 항목이 현재 상태 재검증에서 검출됨.
- 동일 교원 식별값 중복
- 2.28 실제현원 누락
- 정원키 중복
- 학교기본정보 미등록 학교
- 현임교/희망교 학교마스터 불일치
- 미처리 인원
- 인원보존 불일치

## 이번 검증에서 발견해 수정한 오류
- `3.1정원`이 머리글 정규화 후 `31정원`이 되지만 판독규칙은 `301정원`만 찾던 오류
- 기존 `학교만기` / `지역만기`를 새 표준 `관내전보`로 자동 호환
- 기존 `청간전입`을 `타시군전입`으로 자동 호환
- 관외명부는 `구분 + 사유`를 함께 읽어 타시군/타시도/퇴직/휴직 등을 판정
- 타시군·타시도 전입자는 제천 현임교가 없어도 정상 처리

## 결론
정상 100명 기준값과 자동배치 핵심 원칙은 회귀검증을 통과했다. 입력 4종은 결원확정 전에 구조검증을 수행하며, 오류유도 자료의 핵심 오류를 사전에 차단하도록 보완했다.
