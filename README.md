# 제천 교원 내신전보 프로그램

제천교육지원청 교원 내신전보 업무를 보조하기 위한 Python + HTML/JavaScript 하이브리드 프로그램입니다.

## 버전
- v3.2.3 입력서식·업무흐름 강화
- 업무 흐름: 발령 및 전보설정 → 기준자료 등록 → 결원 확정 → 자동·충원 배치 → 최종검증 → 전의안 → 발령통지서

## 자동배치 기본 원칙
1. 복직·복귀
2. 관내전보(명부 위쪽이 높은 순위, 상위순위자의 2지망이 하위순위자의 1지망보다 우선)
3. 타시군 전입
4. 타시도 전입
5. 비정기 전입
6. 신규임용

## 실행
Windows에서 `start.bat`을 실행합니다. Python이 없으면 `setup_python.bat`을 이용해 준비할 수 있습니다.

## 개인정보 보호
실제 인사자료, 백업, 출력물, 저장 데이터는 저장소에 포함하지 않습니다. `.gitignore`에서 `data/`, `backup/`, `output/` 및 사용자 입력 파일을 제외합니다.

## 웹 라이브러리
GitHub 소스판은 저장소 용량과 라이선스 파일 배포를 최소화하기 위해 SheetJS와 Font Awesome을 CDN에서 불러옵니다. 실사용 포터블 배포본은 별도 패키지로 관리하는 것을 권장합니다.

## 주의
이 프로그램은 인사 업무 보조 도구입니다. 최종 인사결정과 발령 전에는 반드시 담당자가 현행 인사계획·지침과 원자료를 대조하여 검증해야 합니다.
